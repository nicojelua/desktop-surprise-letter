A tiny interactive surprise letter built with Python and Tkinter. Click the envelope, watch a heart draw itself, and reveal a personalized message. 💌

## ♡ features

- Interactive pink envelope
- Animated heart drawn using math
- Customizable love message
- Soft pastel interface
- Beginner-friendly Python code
- No additional Python packages required

## ♡ make it yours

1. Fork this repository or select **Use this template**.
2. Download or clone your copy.
3. Open `surprise.py` in your favorite code editor.
4. Find the message inside `draw_heart()`.
5. Replace `"type your message here"` with your own message.
6. Save your changes!!!

## ♡ run the program

Make sure Python with Tkinter support is installed.

Open a terminal in the project folder and run:

`python surprise.py`

Or on Windows:

`py surprise.py`

Click the envelope to reveal your letter!
